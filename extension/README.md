# LLHelper browser extension

Load this folder as an unpacked extension in Chrome or Edge using the browser's Extensions page and Developer mode.

This is only a safe scaffold. It displays a status marker and does not yet read or fill IGR fields. Before autofill is enabled, add and test label/ID-based mappings against the live form. Fill blank fields only by default, verify after filling, and never click Save/Add/submit/payment or automate CAPTCHA/OTP/eKYC/biometrics.
